# Planeación y Asignación de Tareas del Equipo (VeriFinca)

Esta planeación divide las tareas semanales del proyecto entre los integrantes del equipo (Ray y Adrian), desglosando estrictamente semana por semana según la Guía de Proyecto de Grado.
La distribución se ha realizado en base a la estimación de Puntos de Función (FPA), asignando las tareas específicas de Base de Datos y Arquitectura de Datos a Ray (por su dominio). Dado que Adrian también cuenta con fuertes conocimientos técnicos, se le han asignado responsabilidades de **Alta** dificultad en el Frontend, lógica de cliente, integraciones de interfaz, testing y dashboard.
