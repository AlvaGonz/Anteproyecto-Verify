# JWT Security Audit — VeriFinca

> Date: 2026-06-29 | Agent: security-reviewer | Status: Draft
> Objective: WBS-007 — Audit JWT token storage and auth security

## Audit Scope
- Frontend token storage mechanism
- Token refresh and rotation
- Backend JWT configuration
- CORS, CSRF, rate limiting posture
- SEC-001 human gate triggers

## Findings

### F-01: JWT Storage in localStorage (HIGH)
**Severity:** CRITICAL
**Location:** `src/frontend/web/src/features/auth/services/AuthService.ts`
**Description:** Access tokens are stored in `localStorage`. This is XSS-vulnerable — any script injection can exfiltrate tokens.
**Recommendation:** Migrate to httpOnly secure cookies with SameSite=Strict. Requires CSRF token for state-changing requests.
**SEC-001 GATE:** ⚠️ Migration from localStorage to httpOnly cookies requires human decision — impacts all API client interceptors.

### F-02: Refresh Token Not Rotated (HIGH)
**Severity:** HIGH
**Location:** AuthService refresh logic
**Description:** Refresh token appears to be a long-lived (30 day) static token. No evidence of single-use rotation.
**Recommendation:** Implement refresh token rotation — issue new refresh token each time it's used. Revoke old one immediately.
**Risk:** A leaked refresh token provides persistent access.

### F-03: No Rate Limiting on Auth Endpoints (MEDIUM)
**Severity:** MEDIUM
**Location:** Backend auth controller
**Description:** Login endpoint does not appear to have rate limiting.
**Recommendation:** Apply `[EnableRateLimiting]` with sliding window policy (5 attempts/15min per IP).
**Risk:** Brute force attack surface.

### F-04: CORS Policy (LOW)
**Severity:** LOW
**Location:** Backend Program.cs
**Description:** CORS policy was reviewed and appears correctly scoped to the frontend origin.
**Status:** PASS — no action needed.

### F-05: Bearer Token in Every Request (INFO)
**Severity:** INFO
**Location:** Axios interceptor
**Description:** The API client automatically attaches Bearer token to all requests. This is standard practice.
**Recommendation:** Consider excluding public endpoints (`/public/`, `/health`) from token attachment.
**Status:** INFO — low priority.

## Human Gate: SEC-001
**Triggered:** Yes
**Reason:** JWT localStorage → httpOnly cookie migration is a breaking change affecting:
- All API client interceptors (`apiClient.ts`)
- Backend cookie configuration in Program.cs
- CSRF token implementation needed
- All existing auth tests need updates

**Status:** Requires human architect decision before proceeding.
**Recommended Action:** Create ADR for cookie migration strategy.
