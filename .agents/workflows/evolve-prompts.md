# /evolve-prompts — LOW-FITNESS Evolution Workflow

This workflow automates the optimization of underperforming agent skills.

## Pre-conditions
## Infrastructure Prerequisites
- Active MCP servers required: `mcp-context7-mcp`
  - GATE: Verify active server connection using scanner. If FAIL → stop and report. Do NOT proceed. MAX_RETRIES: 3.

## Steps

0. **Initialize Planning Files** (@planning-with-files)
   - Create the isolated session directory at `.agents/sessions/<id_sesion>/`.
   - Populate `.agents/sessions/<id_sesion>/task_plan.md`, `.agents/sessions/<id_sesion>/findings.md`, and `.agents/sessions/<id_sesion>/progress.md` with the workflow ID `evolve-prompts`, current objectives, and the checklist of steps below before touching any project files.
   - GATE: The directory `.agents/sessions/<id_sesion>/` and the base planning files (`task_plan.md`, `findings.md`, `progress.md`) exist and contain all initial steps. If FAIL → stop and report. Do NOT proceed. MAX_RETRIES: 3.

1. **Audit Fitness**: Scan `.agents/sessions/<id_sesion>/skill-fitness-log.md` for skills with `fitness_label: LOW` or `avg_score < 70`.
   - GATE: Low-fitness skills identified. If FAIL → stop and report. Do NOT proceed. MAX_RETRIES: 3.

2. **Context Gathering**: For each low-fitness skill, read its `SKILL.md` and related `.agents/sessions/<id_sesion>/error-patterns.md` entries.
   - GATE: Necessary context collected for all low-fitness skills. If FAIL → stop and report. Do NOT proceed. MAX_RETRIES: 3.

3. **EvoPrompt Execution**:
   - Call Groq 8B with the "Differential Evolution" prompt.
   - Use high-scoring tasks from `.agents/sessions/<id_sesion>/loop-log.md` as "positive examples" if available.
   - GATE: Mutation successfully generated by Groq. If FAIL → stop and report. Do NOT proceed. MAX_RETRIES: 3.

4. **Validation**: Check if the mutated `SKILL.md` preserves required YAML headers and structural markers.
   - GATE: Mutation validated and matches all structural standards. If FAIL → stop and report. Do NOT proceed. MAX_RETRIES: 3.

5. **Deployment**: Overwrite the `SKILL.md` file.
   - GATE: Mutation safely written to the target `SKILL.md` file. If FAIL → stop and report. Do NOT proceed. MAX_RETRIES: 3.

6. **Logging**: Update `last_evolved` in `.agents/sessions/<id_sesion>/skill-fitness-log.md`.
   - GATE: Skill fitness log updated. If FAIL → stop and report. Do NOT proceed. MAX_RETRIES: 3.

7. **Commit**: `chore(agent): evolve low-fitness skills [skill_names]`
   - GATE: Changes committed with conventional commit tag format. If FAIL → stop and report. Do NOT proceed. MAX_RETRIES: 3.
