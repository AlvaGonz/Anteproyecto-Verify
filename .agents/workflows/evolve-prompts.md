# /evolve-prompts — LOW-FITNESS Evolution Workflow

This workflow automates the optimization of underperforming agent skills.

## Steps

0. **Initialize Planning Files** (@planning-with-files)
   - Create or update `.agents/docs/PWF/task_plan.md` with the workflow ID `evolve-prompts`, current objectives, and the checklist of steps below.
   - GATE: The file `.agents/docs/PWF/task_plan.md` exists and contains all steps. If FAIL → stop and report. Do NOT proceed.

1. **Audit Fitness**: Scan `tasks/skill-fitness-log.md` for skills with `fitness_label: LOW` or `avg_score < 70`.
   - GATE: Low-fitness skills identified. If FAIL → stop and report. Do NOT proceed.

2. **Context Gathering**: For each low-fitness skill, read its `SKILL.md` and related `tasks/error-patterns.md` entries.
   - GATE: Necessary context collected for all low-fitness skills. If FAIL → stop and report. Do NOT proceed.

3. **EvoPrompt Execution**:
   - Call Groq 8B with the "Differential Evolution" prompt.
   - Use high-scoring tasks from `tasks/loop-log.md` as "positive examples" if available.
   - GATE: Mutation successfully generated by Groq. If FAIL → stop and report. Do NOT proceed.

4. **Validation**: Check if the mutated `SKILL.md` preserves required YAML headers and structural markers.
   - GATE: Mutation validated and matches all structural standards. If FAIL → stop and report. Do NOT proceed.

5. **Deployment**: Overwrite the `SKILL.md` file.
   - GATE: Mutation safely written to the target `SKILL.md` file. If FAIL → stop and report. Do NOT proceed.

6. **Logging**: Update `last_evolved` in `tasks/skill-fitness-log.md`.
   - GATE: Skill fitness log updated. If FAIL → stop and report. Do NOT proceed.

7. **Commit**: `chore(agent): evolve low-fitness skills [skill_names]`
   - GATE: Changes committed with conventional commit tag format. If FAIL → stop and report. Do NOT proceed.
